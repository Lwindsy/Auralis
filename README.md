# Auralis

Auralis aims to help you discover albums from music you already enjoy. Start with a few favorite albums, describe what you want to hear, and get recommendations with clear reasons.

Auralis希望帮助你从喜欢的音乐出发，发现下一张值得听的专辑。提供几张种子专辑，说说这次想听什么，即可获得带具体理由的推荐。

## Availability / 当前状态

The product is still being designed. There is no runnable application or installable release yet. This repository is reserved for the product and the instructions its users need.

产品仍在设计中，目前没有可运行应用或可安装版本。本仓库仅用于产品本身及使用者需要的说明。

## Planned experience / 计划中的体验

- Discover albums from 1–10 seed albums and your current listening preferences.
- Receive a configurable number of recommendations (three by default), with short reviews and reasons for each choice.
- Understand missing information and limitations instead of receiving invented results.

- 从1–10张种子专辑和本次听歌偏好出发发现专辑。
- 获得数量可配置的推荐（默认三张），附简短乐评和具体选择理由。
- 对信息不足和结果限制给出说明，不编造结果。
